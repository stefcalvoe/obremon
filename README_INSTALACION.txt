🚀 CÓMO INSTALAR (3 PASOS SIMPLES)

PASO 1: Descomprime este archivo ZIP
- Click derecho en la carpeta → "Extraer aquí"
- O arrastra los archivos a una carpeta

PASO 2: Ejecuta el instalador
- Haz DOBLE-CLICK en: INSTALAR.bat
- Verás una pantalla negra con instrucciones
- Presiona cualquier tecla cuando termine

PASO 3: ¡Listo!
- En tu ESCRITORIO verás: "Aforador AMSA"
- Haz doble-click para abrir
- ¡Ya puedes empezar a contar!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📂 DÓNDE SE INSTALA

- Carpeta: C:\Users\[TuUsuario]\Documents\Aforador_AMSA\
- Acceso directo: ESCRITORIO > "Aforador AMSA"
- Datos guardados: Carpeta automáticamente

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚙️ REQUISITOS MÍNIMOS

✓ Windows 7, 8, 10 o 11 (64 bits o 32 bits)
✓ Google Chrome (o Firefox, Edge)
✓ Conexión a internet (para descargar fuentes - solo primera vez)
✓ 200 MB libres en disco duro

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎮 PRIMEROS PASOS DESPUÉS DE INSTALAR

1. Haz doble-click en "Aforador AMSA" del escritorio
2. Se abrirá en tu navegador (Chrome)
3. Verás la aplicación con 3 paneles:
   - IZQUIERDA: Video Player (grande)
   - CENTRO: Lista de videos cargados
   - DERECHA: Controles y datos

4. Click en "📁 CARGAR VIDEOS"
5. Selecciona un archivo .mov o .mp4
6. ¡Comienza a contar!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❓ ¿PROBLEMAS EN LA INSTALACIÓN?

1. ERROR: "INSTALAR.bat no existe"
   → Asegúrate de haber extraído el ZIP completo

2. ERROR: "Chrome no encontrado"
   → Instala Google Chrome desde: https://www.google.com/chrome/
   → Luego intenta nuevamente el instalador

3. ERROR: "Permiso denegado"
   → Haz click DERECHO en INSTALAR.bat
   → Selecciona "Ejecutar como administrador"

4. La aplicación no abre
   → Intenta abrir manualmente el archivo HTML:
   → Busca: Aforador_AMSA_v16.15_IA.html
   → Haz DOBLE-CLICK (debe abrir en navegador)

📞 SOPORTE TÉCNICO

Si tienes problemas:

1. Verifica tener Google Chrome instalado
2. Intenta instalar de nuevo desde cero
3. Si sigue sin funcionar, copia la carpeta:
   C:\Users\[TuUsuario]\Documents\Aforador_AMSA\
   Y envíala al administrador
